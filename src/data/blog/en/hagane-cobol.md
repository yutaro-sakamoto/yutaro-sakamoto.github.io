I have been developing [opensource COBOL 4J](https://github.com/opensourcecobol/opensourcecobol4j), and I have now released [Hagane COBOL](https://github.com/yutaro-sakamoto/Hagane-COBOL), a fork of it.

The project page is at [https://yutaro-sakamoto.github.io/Hagane-COBOL/](https://yutaro-sakamoto.github.io/Hagane-COBOL/).

The first release is [v1.0.0](https://github.com/yutaro-sakamoto/Hagane-COBOL/releases/tag/v1.0.0). It includes more advanced features than opensource COBOL 4J 2.1.0, the latest version at the time of writing. See the release notes for details.
